# Bake & Bouffees Digital

Build a mobile-first, standalone digital ordering web app for a premium bakery named 'Bake and Bouffees'. Use a beautiful, modern luxury theme with soft pastel pink, white, and gold accents.

Use the uploaded photos as the main cake images in the catalog. Make sure these images are embedded locally using correct relative paths so they load quickly and perfectly without breaking when the app is published and hosted live.

Features needed:

A stunning hero section with a large banner displaying her best cake photo.

A categorized digital catalog for 'Custom Cakes', 'Cupcakes', and 'Baking Hampers' with price placeholders (e.g., ₹1,500). Each item should have dropdown options for 'Select Flavor' (Vanilla, Chocolate, Red Velvet) and 'Select Size' (0.5 Kg, 1 Kg, 2 Kg).

A working shopping cart counter.

A clean, standalone checkout form inside the app where customers type their Name, Phone Number, Delivery Date, and Address, then click a prominent 'Place Order' button that shows a success message.
